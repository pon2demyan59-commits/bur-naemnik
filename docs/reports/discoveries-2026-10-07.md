# Доработки: мастер, артефакты, рация и склад

- [x] Новый рисованный аватар строительного мастера подключён в диалогах, строительстве и складе.
- [x] Точный каталог из 200 утверждённых названий: два на каждый из 100 этажей. На всех четырёх реализованных этажах артефакты скрыты в породе.
- [x] Находка при бурении, сбор открытого артефакта рядом с буром, включая блоки, разрушенные пауками. До разрушения блока предмет не виден.
- [x] Коллекция в инвентаре, сохранение количества повторов. Эффекты, продажа и обмен не добавлены: они ещё не определены.
- [x] Позиции и найденные экземпляры сохраняются между входами. Через 24 часа позиции артефактов обновляются при следующем входе на этаж. Текущий этаж во время игры не меняется. Если старый этаж полностью выкопан, восстанавливаются только недостающие блоки с артефактами вдали от бура и сюжетных площадок. Общее землетрясение с восстановлением всех блоков/монстров этим изменением не реализуется.
- [x] Настройка «Убрать рацию в инвентарь»: скрывает всю рацию с игрового экрана. Текст задания и ориентир доступны в инвентаре, настройка сохраняется.
- [x] Первый склад появляется готовым после возвращения спасённого мастера на базу. Без покупки, расхода материалов и таймера. Под его площадкой автоматически расчищается порода. Строительство следующих зданий по-прежнему открывается спасением мастера.
- [x] Загрузки старых сохранений с открытым строительством получают склад. Готовый склад, перенесённое положение и запас сохраняются. Награда за готовый склад выдаётся один раз.
- [ ] Бонусные ящики: ожидается утверждённый список от пользователя. В каноне есть правило их обновления, но нет подтверждённой таблицы содержимого, количества ящиков и размеров наград. Предыдущий случайный лут был предложением, не утверждённым списком.

## Проверки

118 автоматических тестов прошли, включая каталог, позиции на всех четырёх этажах, сбор и перезагрузку, суточное обновление и повторы, бесплатное появление склада и настройку рации. Сборка и проверка JavaScript прошли.

Проверка в реальном Phaser/Chromium: готовый склад и сохранённый запас, новый портрет и меню при 1440×900, 390×844 и 844×390, переключение настройки рации и задание в инвентаре, сбор артефакта на этаже и сохранение находки. Без ошибок страницы и повреждённых изображений.
