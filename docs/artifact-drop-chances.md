# Выпадение артефактов — утверждено 08.10.2026

Заменяет прежние два фиксированных артефакта на этаж. Шанс всей редкости на один разрушенный буром блок. Один общий бросок: максимум один предмет с блока, без гарантии и без лимита на этаж. После выбора редкости — один из 20 видов с равным шансом. Все 200 видов доступны на любом этаже. На базе выпадения нет, разрушение монстрами не выдаёт игроку артефакты. Повторы сохраняются, составы коллекций и бафы не меняются.

Между контрольными этажами — линейная интерполяция. Обычная редкость всегда 0,1%. Вероятность конкретного вида — шанс категории / 20. Старое поле floor в каталоге хранит исходный порядок, не ограничивает выпадение. Старые скрытые позиции игнорируются; найденные экземпляры сохраняются, разрушенные блоки не восстанавливаются при миграции. Новые броски возможны только на новых разрушенных блоках. Механика общего обвала остаётся отдельной задачей: этот патч не реализует восстановление этажей или рекламу.
