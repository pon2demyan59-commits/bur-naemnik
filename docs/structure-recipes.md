# Полный список рецептов сооружений

65 рецептов: 15 зданий, 40 оборонительных сооружений и 10 видов оружия. Состав обороны и оружия сохранён из согласованного канона. Количества материалов для зданий — стартовый баланс; три действующие стройки используют прежние рецепты. Размеры, руководители и роли зданий сверены с таблицей Miro.

Первый склад остаётся бесплатным. Рецепт склада предназначен для будущих дополнительных экземпляров. Сюжетные здания сейчас восстанавливаются по заданиям; их рецепты дополнительных экземпляров подготовлены для будущей системы строительства. Плавильня, цех сплавов, сборочный цех, лаборатория, зал славы и все оборонительные сооружения пока имеют рецепты, но их размещение и работа ещё не реализованы.

В игре: дом архитектора → «Все рецепты». Выбор раздела и поиск по названию либо материалу. Карточки ясно отмечают будущие проекты. Магазин продаёт только четыре ранее реализованных чертежа. Случайное выпадение рецептов из блоков не добавлялось.

## Улучшения

Склад: чертёж расширения 300 кредитов один раз; следующий уровень 200 × 1,25^(текущий уровень − 1), округление вверх, +100 единиц каждого материала. Рецепт материала для улучшения склада не вводится, сохраняется оплата кредитами. Улучшения остальных зданий предстоит определить отдельно. Улучшения оружия и бура продолжают работать в своих сервисных меню.
