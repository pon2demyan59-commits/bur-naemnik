# Утверждённые входные экраны — 6 октября 2026

1. Главная — многоплановая панорама: огромный бур, бункер №72, защитные башни, Шуршуны, кнопка «ВХОД». Это образ будущей развитой базы, не сюжетный старт.
2. «ВХОД» ведёт в полноценное меню. Утверждён физический пульт с объёмными кнопками. Зелёный терминал отклонён как слишком похожий на Fallout.
3. Для новичка — «НАЧАТЬ ИГРУ», для игрока с сохранением — «ПРОДОЛЖИТЬ».
4. Сюжетный старт остаётся прежним: заваленная площадка 50×50, герой садится в бур, спасает Серёгу Т.
5. Стиль — яркая объёмная мультяшная графика, оригинальный ретро-футуризм и постапокалипсис, без жестокости.

Кнопки «Настройки», «Как играть», «Об игре» и адаптивное отображение реализованы как вспомогательные элементы меню. Игровая механика, баланс и канон не менялись.

Файлы `public/assets/ui/title.webp` и `console.webp` — утверждённая главная и пульт с очищенными полями для динамических надписей.
