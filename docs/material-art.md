# Оформление добываемых блоков

Все 13 добываемых материалов из текущего canon-miro.txt подключены к одному листу public/assets/game/material-surfaces.webp. Астерион отмечен в каноне как недобываемый, поэтому для него нет блока. Материалы старых версий проекта не добавлены в текущий список.

| Материал | Рисунок |
| --- | --- |
| Земля | Тёплый рыхлый грунт с мелкой галькой |
| Камень | Серые цельные куски, крупные угловатые трещины |
| Железная руда | Тёмная порода с ржавыми красными включениями |
| Медная руда | Оранжевые жилы и бирюзовая окись |
| Боксит | Терракотовая зернистая порода со светлыми округлыми включениями |
| Оловянная руда | Серебристые угловатые вкрапления в тёмном сланце |
| Цинковая руда | Янтарные гранёные включения в коричневом камне |
| Никелевая руда | Оливково-зелёные минеральные пятна |
| Хромовая руда | Почти чёрные полосатые включения с фиолетовым металлическим отблеском |
| Титановая руда | Стальные синие вытянутые минеральные пластины |
| Вольфрамовая руда | Светлые крупные кристаллические лезвия |
| Золотосодержащая руда | Яркие золотые разветвлённые прожилки |
| Ксенорит | Тёмная фиолетовая порода с голубыми светящимися жилами |

Лист сгенерирован встроенным imagegen. Промпт: квадратный атлас 4 × 4 без подписей, промежутков, рамок и пустого фона; каждый квадрат полностью заполнен видом сверху на свой материал, в рисованном стиле подземной игры. Первые 13 ячеек соответствуют таблице, последние три — дополнительные варианты земли, камня и железа. Затем изображение уменьшено до 640 × 640 и сохранено в WebP. Каждый исходный квадрат имеет 160 × 160 пикселей, в игре клетка остаётся 64 × 64.

Каталог src/materials.js задаёт соответствие ячеек материалам. Карта выбирает настоящую текстуру через world.material(), а не перекрашивает землю. Для каждого материала есть отдельные поверхности, открытые боковые грани и угловые срезы. Соседние заполненные клетки разных материалов не получают ложный открытый край. После разрушения блок и его грани полностью удаляются, остаётся прежний пол бункера и его детали. Детерминированные повороты, отражения и дополнительные варианты разбивают повторяемость текстур.

Атласы и слои создаются только для материалов, реально встречающихся на текущей карте. По новой инструкции пользователя на текущих шахтных этажах 1 и 2 случайно встречаются все 13 материалов. На базе бункера №72 по-прежнему только земля. Расположение материалов задаётся отдельным сохраняемым seed каждого этажа; переходы, загрузка и бурение не меняют состав остальных клеток. Блоки земли имеют прежнюю прочность 1, камень и руды — 2,5 для текущего прототипа. Подробная экономика разных материалов ещё не введена: загрузка и начисление кредитов работают как прежде.


Появление руд соответствует таблице и итоговым правилам из загруженного проекта «Вставленный текст(1).txt». Для каждой металлической руды заданы шансы на 1-м, 50-м и 100-м этажах, между ними применяется линейная интерполяция. Все руды имеют ненулевой шанс с первого этажа; строгих этажей открытия нет. Например, железо: 3% / 8% / 12%; медь: 1,5% / 5% / 8%; ксенорит: 0,0001% / 0,001% / 0,005%. Точная встречаемость случайна: редкая руда может отсутствовать на конкретном этаже. Астерион не появляется в блоках.

Первое числовое поле старой таблицы — прочность, а не этаж открытия. В каталоге оно называется canonicalHardness. Эта правка касается появления: игровой баланс прочности и начисления кредитов сохранён. Камень занимает прежние 25%, земля заполняет остаток после распределения руд. Новые правила применяются к неразрушенным блокам существующих этажей без сброса прогресса. Частично пробурённые блоки сохраняют свой прежний материал через overrides, остальные получают распределение проекта по уже сохранённому seed.

При обновлении старого сохранения выкопанные клетки остаются свободными, а частично повреждённые блоки сохраняют прежний материал и долю нанесённого урона. Проход возле лифта и клетки сюжетных объектов свободны от случайных залежей. Атласы руд используют четыре повёрнутых варианта, камень и железо — восемь; это уменьшает память при одновременном отображении всех материалов.
