# БУР: Забытые внизу

Мультяшный подземный рогалик для Яндекс Игр. Phaser 3.90.0, JavaScript.

## Запуск

```sh
npm ci
npm run dev
```

Открыть http://localhost:4173. `npm run build` собирает автономный `dist/` с локальным Phaser и ассетами, без CDN. Разработку ведём в `development`; готовые этапы переносим в `main` через PR.

## Реализовано

- Утверждённая главная: бур, дверь №72, башни, Шуршуны; «ВХОД» открывает меню.
- Меню — физический пульт. Живые кнопки поверх изображения, мышь, касание, клавиатура.
- «НАЧАТЬ ИГРУ» для новичка, «ПРОДОЛЖИТЬ» при валидном сохранении.
- Настройки, справка, информация об игре, возврат на главную.
- Мобильная вертикальная компоновка с крупными кнопками; горизонтальная сохраняет утверждённый макет.

Игровая база и первый квест пока не реализованы. Основная кнопка сообщает об этом и не создаёт фиктивное сохранение. SDK, реклама, покупки и облачные сохранения Яндекс Игр будут отдельным этапом.

## Контракт сохранения

Ключ `bur-naemnik.save.v1`, JSON `{ "version": 1, "progress": { "location": "base" } }` (минимальный контракт; дополнительные игровые данные добавляет игровая сцена). Повреждённые или несовместимые записи не включают «ПРОДОЛЖИТЬ». Настройки хранятся отдельно и не считаются игровым прогрессом.

Для подключения базы обработать отменяемое событие `bur:play` на `window`, вызвать `event.preventDefault()` и открыть игровую сцену; `event.detail.save` содержит сохранение или `null`.
