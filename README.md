# БУР: Забытые внизу

Мультяшный подземный рогалик для Яндекс Игр. Phaser 3.90.0, JavaScript.

## Запуск

Для запуска игры скачайте репозиторий и откройте `index.html` в браузере. Готовые `public/game.js`, Phaser и изображения включены в репозиторий. Они запускаются без установки Node.js и без предварительной сборки.

Для разработки:

```sh
npm ci
npm run dev
```

Открыть http://localhost:4173. `npm run build` обновляет готовые файлы в `public/` и собирает автономный `dist/` с локальным Phaser и ассетами, без CDN. После изменений в `src/` нужно пересобрать и закоммитить обновлённый `public/game.js`. Разработку ведём в `development`; готовые этапы переносим в `main` через PR.

## Реализовано

- Утверждённая главная: бур, дверь №72, башни, Шуршуны; «ВХОД» открывает меню.
- Меню — физический пульт. Живые кнопки поверх изображения, мышь, касание, клавиатура.
- «НАЧАТЬ ИГРУ» открывает первую игровую базу, «ПРОДОЛЖИТЬ» возвращает к сохранению.
- Настройки, справка, информация об игре, возврат на главную.
- Мобильная вертикальная компоновка с крупными кнопками; горизонтальная сохраняет утверждённый макет.

- Земля — непрерывный массив с объёмными срезами и тенями только по краям проходов. При бурении открывается потёртый бетонный пол бункера с редкими решётками, трубами и кабелями; соседние края обновляются сразу.
- Первая база 50×50: перемещение бура, бурение завалов, сохранение проходов и частичного повреждения блоков.
- Задание «Голос за завалом»: рация, Серёга Т, спасение по E/пробелу или кнопке.
- Компактный спрайт бура с поворотом вокруг корпуса, непрерывное движение с разворотом на ходу, плавный разгон и торможение и контрастные движущиеся звенья гусениц. Пыль, искры и сколы при бурении; головка постепенно краснеет и остывает. Нагрев — визуальный эффект, без изменения баланса.
- Камера следит за буром; мобильные кнопки направлений; выход в меню сохраняет прогресс.

Лифт и Породник отмечены на карте, но их запуск будет следующим этапом. Экономика, грузовой отсек, этажи, враги, SDK, реклама, покупки и облачные сохранения Яндекс Игр ещё не подключены. Время расчистки одного блока завала (1 секунда) — стартовое значение прототипа, не утверждённый баланс.

## Контракт сохранения

Ключ `bur-naemnik.save.v1`, JSON `{ "version": 1, "progress": { "location": "base" } }` (минимальный контракт; дополнительные игровые данные добавляет игровая сцена). Повреждённые или несовместимые записи не включают «ПРОДОЛЖИТЬ». Настройки хранятся отдельно и не считаются игровым прогрессом.

Сцена `Base` получает сохранение из меню. В `progress` хранятся координаты `x/y`, массив `cleared` (номера клеток), массив `damage` (частичная расчистка), флаги `heard/rescued`, точное положение и направление бура в `drive`. Старые сохранения поддерживаются. Настройки не считаются прогрессом. Новая игра создаёт сохранение после входа в реальную игровую сцену.

## Управление и проверка

- WASD / стрелки: движение. Последнее нажатое направление имеет приоритет; поворот происходит на ходу, после отпускания — короткое плавное торможение. У стен и при входе в узкий проход бур мягко выравнивается; на открытой площадке помощь отключена. Удерживать направление к завалу: бурение.
- E / пробел или «Спасти Серёгу»: взаимодействие рядом с человеком.
- Escape / «Меню»: сохранить и вернуться в меню.
- Телефон: четыре кнопки направлений и отдельная кнопка спасения.
- `npm test`: проверки сохранения разрушений, частичного повреждения, условий спасения и повреждённых записей, плавности поворотов и нагрева.
